# UI 与告警处理优化（0.3.1 前置改进）

- 日期：2026-08-16
- 范围：`AGENTS_PLAN` 完成后的专项打磨——告警（问题面板）体系重构 + 界面可用性优化

## 告警处理

| 能力 | 说明 | 证据 |
|---|---|---|
| 统一入口 `AlertCenter`（`src/ui/alerts.rs`） | 去重（同 code+消息合并计数 ×N）、上限 200 条（最旧淘汰）、按 code 清除（状态迁移）、全清、逐条关闭 | 8 个单元测试 |
| 严重度过滤 | 面板头部 Errors/Warnings/Info 三档开关，各带实时计数；过滤后空态提示 | kittest 交互测试 |
| 自动展开 | 任何错误（含重复错误）到达即展开问题面板一次；信息级绝不打扰 | shell 单测 + 面板测试 |
| 跳转定位 | 带行列的告警（源码 Apply 失败、XSD 诊断）可点击 → 源码面板显示跳转目标提示并聚焦 | kittest 测试 + Localization 插值断言 |
| 非阻塞横幅 | 外部文件修改从居中模态改为顶部横幅（Reload/Keep/Ignore），不再劫持焦点 | kittest 测试（渲染 + 关闭） |
| 状态可视化 | 工具栏与状态栏错误/警告/信息 chip（按最高严重度着色、计数、点击开合面板）；面板可折叠 | 快照基线更新（12 组） |

## UI 优化

- 工具栏：新增撤销/重做/查找/告警按钮（图标 + 本地化悬停提示，禁用态正确）。
- 标签栏：横向滚动（多标签不再换行）、活动标签高亮、脏标签着色。
- 问题面板：严重度图标 + 着色行、重复计数、位置后缀、逐条 ×、Clear all、折叠按钮、可拖调高度。
- 源码面板：跳转目标提示条（可关闭）；草稿警示条保持。
- XSD 验证结果："valid" 判定改为本次运行无诊断（不再被历史告警干扰）。

## 过程中修复的真实缺陷

1. `SeverityFilter` 派生 `Default` 全为 false——面板默认过滤掉所有告警（发现于 kittest 探针；改为手动 `Default = ALL`，附回归测试）。
2. Fluent 内联占位符语法错误：`{line}` 应为 `{ $line }`，导致坐标/计数不插值（两个新键已修正，中英同步）。
3. `#[allow(dead_code)]` 属性在模块插入时错挂目标（修正归属）。
